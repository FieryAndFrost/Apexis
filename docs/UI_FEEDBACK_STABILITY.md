# 同步提示布局稳定性（2026-09-17）

## 本次修复

- 正文从可变高度的进度/提示栏中分离，放在固定尺寸的页面区域内。
- 进度条位于页面顶部固定 2px 浮层，显示、隐藏、进度变化均不改变正文约束。
- 错误或通知使用右下角单卡片浮层，优先展示错误；重复消息原位更新，不叠加卡片、不播放位移动画。
- 卡片限制宽高，长错误可在卡片内滚动，关闭和重试按钮始终保留；不阻断卡片以外区域的点击。
- 通知/快照同步失败恢复后清除对应旧错误；写入拒绝的错误不会因随后同步成功而被误清除。

## 验证

`test/feedback_layout_test.dart` 在 1280×860、375×812、812×375，1×/2× 字体及减少动画模式下验证：

- 页面区域、页面容器、滚动视口的矩形尺寸和位置不变。
- 滚动偏移、最大滚动范围及页面 State 不变。
- 长错误、关闭、重试和浮层外的导航点击可用。
- 三种尺寸的提示状态视觉回归通过；现有界面金图无需更新。

完整测试 86 项通过。此次未改固件，也未修改 WRITE/revision/ACK 校验规则；这是提示引起的布局位移修复，不等于消除所有协议版本冲突或改变参数元数据失效策略。

## 500 ms 延迟反馈（后续优化）

- 普通同步及操作开始后延迟 500 ms 才展示全局进度和禁用控件；提前结束则取消计时，不闪现忙碌状态。连续排队工作按一段忙碌时间计时。
- 首次连接尚无可用视图时仍不可编辑；断线立即禁止编辑，不等待 500 ms。错误提示不延迟。文件导入/导出的专用传输对话框仍保留。
- `ready` / `busy` 保留真实通信状态；`presentationReady` / `showBusyFeedback` / `editable` 面向界面。UI 的 access 切片不因短暂忙碌广播全局禁用；协议等待者仍能收到真实状态变化。
- 宽限期接受的新操作串行执行（最多 16 个在途及等待项），等待同步 ACK，使用执行时的 revision；会话、同步边界、音色、效果结构或参数定义变化后取消旧操作。重连不继承旧会话队列。
- 主界面沿用固定 2px 进度槽；预设列表也改为固定 4px 进度槽，显示与隐藏不挤动内容。按照 UI/UX 技能的反馈与布局稳定性规则实现。
- `test/busy_feedback_test.dart` 覆盖 499/500 ms 边界、短操作取消、无关更新不重置计时、连续队列、初次连接、断线/销毁、串行写入、失效编辑及重连隔离；原有布局和金图测试继续覆盖手机竖横屏、2 倍字体与减少动画。

本次不改变下位机固件、协议 ACK/WRITE 校验或参数描述缓存失效策略；延迟的是界面反馈，不是发送请求。

验证结果：`flutter analyze` 无问题；`flutter test` 全部 98 项通过（含 12 项新增延迟反馈/队列测试）。

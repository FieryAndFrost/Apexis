## 测试结果

1. 首次写入测试在完整 GT1B 备份阶段被 `00/01/35 error=08`（STALE）拒绝。设备通知显示当前音色输出音量 88→87→88、revision 12→13→14。`mutationsStarted=false`，没有执行参数写入，因此无需恢复。
2. 16:21:18–16:21:28 的只读观察中，20 个采样均 ready，revision 保持 14、输出音量保持 88，没有新增参数通知。系统、鼓机、Looper、调音器四项 GET 均成功。十秒稳定不代表间歇变化已经消除。
3. 16:24 的重试仍在备份阶段返回 STALE。设备通知为绝对偏移 414（当前音色输入音量）27→28，revision 19→20；同样没有开始参数写入。
4. 重试期间串口捕获到三条 `timer_no_response: app_core`；此后运行时统计继续输出，未据此认定死机或看门狗复位。

固件整库导出期间会校验参数 revision；变化后取消导出并返回 STALE。因此当前备份失败有对应的设备参数变化证据，并非仅凭应用提示推断。尚未确认测试期间用户是否操作旋钮或其他客户端，不能认定为 ADC 抖动。固件旋钮代码已有 ADC 死区，不能描述为完全没有过滤。

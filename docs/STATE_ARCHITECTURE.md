# 界面状态与重建边界

## 数据路径

```text
USB / BLE → ProtocolSession → ApexisController（设备协调与命令门禁）
                                 ↓ 发布完整快照
                         DeviceViewStore
                                 ↓ 按值比较、只通知变化的分区
                         DeviceRegion + 字段投影
                                 ↓
                       当前可见的相关控件
```

- `lib/data/view_state.dart`：不可变 `DeviceSnapshot`、分区通知及结构化比较。GLOB/PATCH、元数据列表与目录 Map 均复制为不可修改容器；会话引用仅作为身份标识。所有分区通知发出前，完整快照已替换，订阅者不会读取到半次发布。
- `lib/data/controller.dart`：保留协议工作缓冲、ACK 就绪、revision/epoch、防过期回包、写入与文件事务。`emit()` 现在发布快照；没有显示状态变化时不通知。原 `ChangeNotifier` 接口仅保留给设备状态等待等兼容路径，主界面不再订阅它。
- `lib/ui/device_region.dart`：订阅指定分区，可进一步选择字段；使用结构化相等比较过滤无关变化，同一快照的多分区通知只产生一次有效更新。隐藏页通过 `TickerMode` 取消订阅，显示前读取最新快照。
- 页面继续通过已有 Controller 查询当前值和调用命令，保留调用接口兼容性；重建依赖由快照定义，而非“任意 emit 就重建”。新增区域应声明完整依赖，不能省略影响显示或编辑权限的字段。

## 订阅划分

| 区域 | 更新依赖 |
|---|---|
| 外壳/连接入口 | 是否连接、设备身份、是否已取得 PATCH |
| 顶栏 | 音色名称/编号/revision、连接和编辑权限 |
| 提示、传输进度 | 错误/提示/进度、编辑权限 |
| 效果链 | UNIT 类型、数量、顺序、启用状态、当前选择、编辑权限 |
| 参数布局 | 效果结构及参数描述的失效/变化 |
| 参数旋钮 | 自身的原始值、编辑权限；描述变化由参数区域处理 |
| 输入/输出/PAN/BPM | 各自的 PATCH 字段、编辑权限 |
| 全局控件 | 各自的 GLOB 字段、编辑权限 |
| EQ 曲线 | EQ 区间；其它全局字段不触发它 |
| LOOP 进度 | position/total/limit；不带动操作按钮与设置 |
| 调音指针/音名 | 指针位置、音名及调准颜色；不带动顶栏和标准音高设置 |
| 资源/鼓型/预设名/连接信息 | 各自独立目录或状态分区 |

Tab、方向动画、滚动位置和拖动草稿属于本地 UI 状态。导航使用独立 `ValueNotifier`，只更新导航和页面容器，不再调用外壳 `setState`。访问过的页面继续按需缓存，不预建未访问页面；断连/换会话/换音色会失效。

## 安全与保留行为

- 保留 240ms 页面位移与 180ms 选中条动画、手机布局和减少动画支持。
- 元数据失效仍会重建参数区；不能为了减少 build 而继续使用过期 TYPE、范围或 UNIT 地址。
- 保留全局写入门禁。目录查询目前仍沿用既有 `run`/busy 协调，不在此轮冒险放开查询与写入并发；这会在相关操作期间更新编辑权限，不应算作“无关更新”。
- 调音器关闭时不发送测量查询；相同轮询结果不发布通知。离开页面、重连或重新同步后，旧轮询结果/异常不污染当前状态。
- 缓存隐藏页关闭 ticker、焦点和命中；未完成的拖动草稿及迟到的结束回调不能提交。
- `Offstage` 不等于零布局开销，窗口缩放/字体等约束变化仍需要布局。`RepaintBoundary` 只隔离绘制，不阻止 build/layout。

## 回归与性能验证

`test/view_state_test.dart` 覆盖不可变快照、按值去重、分区发布的一致性、空轮询和过期响应。

`test/rebuild_scope_test.dart` 通过构建计数验证：一个字段只更新对应区域、切 Tab 不重建外壳/顶栏、隐藏页不更新且返回读取新值、调音/LOOP 高频更新不扩散。包含空值投影回归。

Windows 使用 `integration_test/navigation_performance_test.dart` 的 Profile 演示测试，并保留构建/栅格化耗时原始记录。构建计数证明更新范围，不等于零掉帧；导航首帧、系统调度、输入到呈现延迟仍需独立测量。
